# 🛡️ Suraksha AI
### *Your Shield Against Digital Fraud*

Suraksha AI is an AI-powered fraud detection platform designed to help users identify **scam messages, counterfeit currency, fake QR codes, and malicious payment links** using Explainable AI. The platform provides real-time analysis, transparent reasoning, multilingual voice support, and a unified fraud risk score to make fraud detection accessible, understandable, and reliable for everyone.

---

## 📌 Problem Statement

Digital fraud has become one of the fastest-growing cyber threats. Millions of users lose money due to phishing messages, fake payment QR codes, counterfeit currency, and online scams.

Most existing solutions focus on solving only one type of fraud and often behave like black boxes without explaining why something is considered fraudulent.

**Suraksha AI** addresses this challenge by providing a single intelligent platform capable of analyzing multiple fraud types while explaining every decision in a transparent and user-friendly manner.

# 🚀 Key Features

### 📩 Scam Message Detection
- Detects phishing and scam messages
- Identifies urgency, impersonation and suspicious keywords
- Generates an Explainable AI reasoning trace
- Calculates fraud confidence score

---

### 💵 Counterfeit Currency Verification
- Detects whether a currency note appears genuine or counterfeit
- Supports real-time camera capture
- Image quality analysis
- Transparent feature-based verification

---

### 📷 QR Code Verification
- Real-time QR Scanner
- Detects malicious payment QR codes
- Extracts and verifies QR information
- Identifies suspicious payment URLs

---

### 🌐 Link Verification
- Detects malicious URLs
- Identifies shortened links
- Checks suspicious domains
- Risk scoring

---

### 🧠 Explainable AI
Unlike traditional AI models, Suraksha AI explains every prediction by displaying the reasoning process behind the final result.

Example:

- Suspicious Keywords Detected
- Bank Impersonation Found
- Urgency Language Identified
- QR Redirect Risk
- Image Quality Analysis

---

### 📊 Unified Fraud Risk Score

Suraksha AI combines results from multiple detectors into a single fraud risk score, allowing users to quickly understand the overall threat level.

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/yourusername/Suraksha_AI.git
```

Move into the project

```bash
cd Suraksha_AI
```

Install dependencies

```bash
npm run install:all
```

Run the project

```bash
npm run dev
```

---

# 🔑 Environment Variables

Create a `.env` file.

```env
OPENAI_API_KEY=your_openai_key

ANTHROPIC_API_KEY=your_anthropic_key
```

Without API keys, the application still works using its built-in heuristic detection system.
